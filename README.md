# 🌍 MetScope Visuals

**Professional Weather Visualization - Pure JavaScript Edition**

No TypeScript. No build process. No complexity. Just open `index.html` and it works!

![No Build](https://img.shields.io/badge/build-none-success) ![Pure JS](https://img.shields.io/badge/JavaScript-vanilla-yellow) ![License](https://img.shields.io/badge/license-MIT-blue)

## ⚡ Quick Start

```bash
# Just open the file!
open index.html
```

Or use a simple server:
```bash
python3 -m http.server 8000
# Visit: http://localhost:8000
```

**That's it!** No `npm install`, no build step, no configuration.

---

## ✨ Features

- 🌡️ **Real-time Weather Data** - 7-day forecasts
- 📊 **Interactive Charts** - Powered by Chart.js
- 🗺️ **Global Coverage** - Search any location
- 📈 **Historical Data** - From 1940 to present
- 💾 **CSV Export** - Download your data
- 🎨 **Beautiful UI** - Professional dark theme
- 📱 **Responsive** - Works on all devices

---

## 🎯 How It Works

1. **Search location** - Type any city name
2. **Select variables** - Temperature, wind, precipitation, etc.
3. **Click Visualize** - See interactive charts
4. **Export data** - Download as CSV
